# PUB7: документы для новых пользователей

Исполнитель: Claude Haiku 5.5 (линия claude2). Дата: 2026-10-20.
Итог: **complete** по трём пунктам карточки. Все изменения только в документации и шаблоне issue, код не менялся.

## Что сделано

1. **`docs/TROUBLESHOOTING.md`**: новый раздел «First install» в начале. Он описывает `shura check` и `shura install --dry-run`
   как проверку до установки и разбирает сообщения установщика, которые можно найти поиском:
   - `Install stopped: … is not in the … repository` (проблема каталога, открыть issue);
   - `checksum mismatch for …` (повторный запуск, прокси или антивирус);
   - `No GPU build works here: planning for the CPU instead.` (драйвер, `vulkaninfo --summary`);
   - `The requested <backend> backend has no fitting plan here; planning the Vulkan fallback.` (запуск без `--backend`);
   - `<engine> did not work here (…)` (только итоговое `Install stopped:` значит, что ничего не сработало);
   - скорость ниже прогноза (прогноз MoE на Vulkan не откалиброван, см. `docs/SPEED-ESTIMATES.md`).
   Перед issue предлагается `./scripts/shura doctor`, вывод без имени пользователя и путей.
2. **`README.md` и `README.ru.md`**: раздел «Will it run on my computer?» / «Подойдёт ли мне?» перед «Run it on your hardware»
   / «Запуск на своём железе». Содержание: бэкенд по умолчанию (Vulkan, затем CPU, `--backend` для выбора), память (модель из
   каталога требует около 20 ГиБ на CPU; 16 ГБ ОЗУ без видеокарты не подходит; 8 ГБ VRAM и 32 ГБ ОЗУ подходят в гибридной
   раскладке), скорость (до замера цифры нет; прогноз MoE на Vulkan не откалиброван). Ссылки на `SPEED-ESTIMATES.md` и
   на «First install».
3. **`.github/ISSUE_TEMPLATE/install-failed.md`**: шаблон «Install failed» на английском, как два других шаблона. Поля: железо,
   команда, строка, на которой остановилось, вывод `./scripts/shura doctor` (с просьбой убрать имя и пути), ожидание.

## Решения, которые я принял сам

- **Цифр скорости по железу в README нет.** Планировщик на фикстурах даёт для MoE на Vulkan 109 tok/s на RX 7900 XTX, а
  измерение PUB5 на этой карте дало около 62. Публиковать такую цифру как «честную оценку» нельзя. В README есть только
  факт расхождения (около 1.8 раза) и ссылка.
- **Подпись «оценка, ±X %» в выводе сейчас не появится ни для одной модели из каталога.** Каталог содержит одну MoE-модель, а
  подпись выводится только для плотных моделей (PUB5b). В документации это не обещается.
- **Казахский текст не добавлял** (правило доски).
- **Оба README на одном уровне**: EN и RU с одинаковым содержанием.

## Что НЕ проверено

- Ошибки в `First install` сверены с текстами в коде установщика (`install.py`, `engine.py`), но не воспроизведены на
  реальной машине.
- Числа в README (20 ГиБ, 16 ГБ без видеокарты, 8 ГБ + 32 ГБ гибрид) взяты из прогона планировщика на фикстурах железа,
  а не из измерения. Фикстуры описывают машины, которых у меня нет.
- Ссылки проверены по наличию файлов и якорей в репозитории, не в опубликованном GitHub-рендере.
- `shura doctor` не очищает вывод сам: просьба убрать имя и пути стоит в шаблоне, автоматической очистки нет. Это
  возможное улучшение, отдельной задачей.
- Полный набор тестов: см. строку ниже. Код не менялся, но набор запускался.
