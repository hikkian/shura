Create a git commit for the current changes. $ARGUMENTS

Status:
!`git status --short`

Staged:
!`git diff --cached --stat`

Unstaged:
!`git diff --stat`

Recent commit messages (match this style):
!`git log --oneline -8`

Rules:
- If nothing is staged, stage the changes that belong to one logical change; leave unrelated files alone
  and tell me about them. Never stage files that look like secrets (.env, keys, tokens) or build output.
- Write a concise subject line in the repository's style, and a short body only if the why is not obvious.
- Do not add co-author, "generated by" or tool-attribution lines.
- Commit only; never push.
