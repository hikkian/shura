# sched

Расписание работы магазина: еженедельные окна в часовом поясе магазина.

```python
from sched import Schedule, open_minutes, is_open, next_change
s = Schedule("Europe/Berlin", {0: [("09:00", "17:30")], 4: [("22:00", "02:00")]})
```

* `Schedule(tz, windows)`: `windows` — словарь «день недели (0 = понедельник) -> список окон `("HH:MM", "HH:MM")`».
  Окно задаётся местным (настенным) временем. Если конец <= начала, окно переходит на следующие сутки
  (и принадлежит дню начала). `("00:00", "00:00")` — от местной полуночи до следующей местной полуночи (реальные прошедшие минуты). Окна могут пересекаться или примыкать друг к другу.
* Окно — полуинтервал `[начало, конец)`.
* Местное время, которого нет (пропуск при переходе на летнее время), сдвигается вперёд на длину пропуска
  (02:30 -> 03:30). Местное время, которое бывает дважды (при возврате часов), понимается как первое вхождение.
* `open_minutes(schedule, day)` — сколько реальных (прошедших) минут магазин открыт в календарных сутках `day`
  (`datetime.date`, от местной полуночи до следующей местной полуночи), с учётом ночных окон предыдущего дня.
  Минуты, покрытые несколькими окнами, считаются один раз.
* `is_open(schedule, instant)` — открыт ли магазин в момент `instant` (aware `datetime` в любом поясе).
* `next_change(schedule, instant)` — ближайший момент строго после `instant`, в который магазин переходит из
  открытого в закрытое или наоборот (aware `datetime`); `None`, если смен состояния больше не будет
  (магазин закрыт всегда или открыт всегда). Примыкающие окна не создают смены состояния.
