# calc

```python
from calc import evaluate, ParseError, EvalError
evaluate("2 + 3 * x", {"x": 4})   # 14
evaluate("max(1, 2 ** 3)")        # 8
```

## Язык выражений

Операции от низшего приоритета к высшему:

| приоритет | операции | ассоциативность |
|---|---|---|
| 1 | `+` `-` (двоичные) | левая |
| 2 | `*` `/` `%` | левая |
| 3 | `+` `-` (унарные) | префиксные, можно подряд: `--3` |
| 4 | `**` | правая |

Унарный минус слабее `**`, но справа от `**` он допустим: `-2 ** 2` это `-4`, `2 ** -2` это `0.25`.
`/` — обычное деление (результат float). `%` — остаток с знаком делителя, как в Python (`-7 % 3` это `2`).
Остальные операции над int дают int (точно, без потери разрядов).

Числа (ведущие нули допустимы): `12`, `3.5`, `.5`, `1.`, `1e3`, `2.5E-2`. Пробелы между токенами любые. Имена — переменные из словаря
`variables` (буквы, цифры, `_`, не начинаются с цифры). Функции: `abs(x)` (ровно 1 аргумент),
`min(a, b, ...)` и `max(a, b, ...)` (минимум 1 аргумент). Скобки и вызовы функций — как обычно.
Неявного умножения нет (`2(3)`, `2 x` — ошибки).

## Ошибки

Все ошибки — наследники `CalcError`, у каждой есть `pos` (индекс символа в исходной строке, с 0).

* `ParseError` — выражение записано неверно. `pos` — позиция первого символа, который нельзя принять (токен или символ);
  если выражение оборвалось раньше времени, `pos == len(text)`.
* `EvalError` — выражение записано верно, но не вычисляется: деление на ноль (в `/`, `%` и нуль в отрицательной степени, в том числе вещественный),
  неизвестная переменная или функция, неверное число аргументов, результат не вещественный
  (отрицательное число в дробной степени), переполнение float. `pos` — позиция оператора, имени или функции,
  вызвавших ошибку. В сообщении об ошибке с именем указано само имя.

Никакие другие исключения из `evaluate` наружу не выходят (кроме `TypeError` для нечисловых значений переменных).
