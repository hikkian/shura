# recur

Упрощённый аналог RRULE из iCalendar. Только даты (`datetime.date`), без времени.

```python
from datetime import date
from recur import Rule, expand
r = Rule("MONTHLY", bymonthday=[15], count=3)
expand(date(2025, 1, 10), r, date(2025, 1, 1), date(2025, 12, 31))
# [date(2025, 1, 15), date(2025, 2, 15), date(2025, 3, 15)]
```

## Rule

`Rule(freq, interval=1, byweekday=None, bymonthday=None, count=None, until=None, exdates=())`

* `freq` — `"DAILY"`, `"WEEKLY"`, `"MONTHLY"` или `"YEARLY"`; `interval >= 1` — шаг в периодах (днях, неделях, месяцах, годах).
* `byweekday` — список дней недели (0 = понедельник, допустимы 0..6), только для WEEKLY. `bymonthday` — список чисел месяца,
  только для MONTHLY; отрицательные считаются с конца месяца (`-1` — последний день, `-2` — предпоследний);
  `0` и значения вне `-31..31` недопустимы. Нарушение этих правил или другие неверные параметры — `ValueError`.
* `count` — всего вхождений (>= 1); `until` — последняя допустимая дата, включительно. Если заданы оба, действует то, что наступит раньше.
* `exdates` — даты-исключения: в результат не попадают.

## expand(start, rule, begin, end)

Возвращает отсортированный список (одна и та же дата — один раз, даже если её дают несколько значений `byweekday`/`bymonthday`) дат вхождений `d`, для которых `begin <= d <= end` (обе границы включительно).

* Вхождения не раньше `start`. Сама `start` — вхождение, только если подходит под правило.
* Периоды отсчитываются от периода, содержащего `start`: при `interval=2` берётся каждый второй период.
  Неделя начинается с понедельника.
* Если `byweekday` не задан для WEEKLY, это день недели `start`; если `bymonthday` не задан для MONTHLY, это число месяца `start`;
  YEARLY повторяет месяц и число `start`.
* Дата, которой в периоде нет (31 апреля, 29 февраля в невисокосный год, `-31` в коротком месяце), пропускается:
  вхождения нет и в счёт `count` она не идёт. Сдвигов и «прижимания» к концу месяца нет.
* `count` считает вхождения с самого начала, а не с `begin`; исключённые через `exdates` в счёт `count` входят.
* Результат не выходит за `date.max`.
