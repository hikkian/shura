# Typo guard (опечатки в русском тексте модели)
Файлы: `typo_fix.py` (новый модуль), `lang_guard.py` (StreamGuard держит финальный русский ответ до конца, до 2500 символов), `gateway-typo.patch` (правка `ai_gateway.py`), `test_typo_guard.py` (модульные тесты).
Включается `"typoGuard": true` у модели в `model-launch.json` (включено у ornithi и ornithit). Нужны `hunspell` и словарь `ru_RU` (`sudo dnf install hunspell hunspell-ru`, либо файлы index.dic/index.aff из https://github.com/wooorm/dictionaries/tree/main/dictionaries/ru, положенные как ~/.local/share/hunspell/ru_RU.dic и ru_RU.aff). Без hunspell защита молча ничего не делает.
Как работает: слова из прозы (вне кода, ссылок, путей) проверяются словарём; неизвестные (опечатки, но и жаргон/имена) уходят в один короткий запрос к той же модели (кэш префикса переиспользуется, мышление выключено), она возвращает JSON {"опечатка": "исправление"}; исправление применяется, только если оно близко по редакционному расстоянию (≤3) и либо известно словарю, либо есть в разговоре, либо (жаргон) отличается одной буквой от другого слова ответа. Весь ответ не переписывается, заменяются только слова.
Ограничения: исправляет орфографию, но не грамматику (падежи); ответы длиннее 2500 символов идут потоком без проверки; цена: финальный русский ответ показывается после завершения генерации, плюс 2–4 с на запрос исправлений при подозрительных словах.
